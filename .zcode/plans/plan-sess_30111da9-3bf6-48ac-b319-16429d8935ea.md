## 实施方案：Omnichat Skill 功能

### 设计选择
- **格式**: Markdown + YAML frontmatter（`.skill.md`）
- **匹配**: 先关键词匹配，后续可升级语义匹配
- **Skill 定位**: 提示词增强 + 工具组绑定，可选关联 Workflow 模板
- **范围**: Phase 1 基础框架 + 3 个内置 Skill

### 一、数据层

**SkillEntity**（Room 实体，新增表 `skills`）：
- `id: Long` (autoGenerate), `skillId: String` (唯一标识), `name`, `description`, `version`, `author`
- `triggerPatterns: String` (JSON 数组), `systemPrompt: String`, `requiredToolGroups: String` (JSON 数组)
- `workflowTemplateId: String?`, `isEnabled: Boolean`, `isBuiltin: Boolean`, `createdAt`, `updatedAt`

**SkillDao**：Flow 查询、按 skillId 查找、按启用状态过滤、CRUD 操作

**AppDatabase**：v56→v57 迁移（CREATE TABLE skills），暴露 DAO

### 二、核心引擎

| 组件 | 职责 |
|------|------|
| **SkillRegistry** | 内存注册表，ConcurrentHashMap 管理，类似 ToolRegistry |
| **SkillMatcher** | 关键词匹配：用户消息是否包含 triggerPatterns 中的词 |
| **SkillInstaller** | 解析 `.skill.md` 文件（frontmatter YAML + body），写入数据库 |
| **SkillManager** | 业务逻辑层：初始化、安装内置 Skill、匹配、启用/禁用 |
| **BuiltinSkills** | 3 个内置 Skill 定义 |

### 三、ChatViewModel 集成

在 `generateSystemPrompt()` 中，记忆注入之后、MCP 工具列表之前插入：
```kotlin
val matchedSkills = skillManager.matchByIntent(userMessage)
// 注入匹配 Skill 的系统提示词
// 确保 requiredToolGroups 已启用
```

### 四、UI 层

- **MainScreen.SettingsView**：新增第 6 个标签 "Skills"
- **SkillsView**：已安装 Skill 列表（卡片 + 开关）、安装按钮（文件选择器导入 `.skill.md`）
- 聊天界面输入框上方显示当前激活的 Skill Chip

### 五、3 个内置 Skill

| Skill | 触发词 | 说明 |
|-------|--------|------|
| 周报生成器 | 周报、weekly、工作总结 | 搜索记忆 → 生成结构化周报 |
| 深度研究 | 研究、调研、分析、调查 | 使用 SubAgent 进行多步搜索 |
| UI 调整 | 改界面、换主题、改颜色 | 使用 UI 工具组调整外观 |
